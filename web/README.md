# AIsample1 Web GUI

HTML・CSS・JavaScriptで作成した家計簿アプリのWeb版です。

## ファイル構成

- `index.html`: 画面の構造
- `style.css`: 色、レイアウト、レスポンシブデザイン
- `app.js`: 支出の登録・削除、合計計算、入力チェック、保存処理

## 起動方法

1. この `web` フォルダーをダウンロードするか、リポジトリをクローンします。
2. `index.html` をChromeやEdgeで開きます。
3. 日付、カテゴリ、金額を入力して「支出を登録する」を押します。
4. 支出一覧、合計金額、削除機能を確認します。

サーバーや追加ライブラリは不要です。

## 保存について

支出データはブラウザの `localStorage` に保存されます。同じブラウザ・同じ保存領域で開いた場合、再読み込み後もデータが残ります。Windows Forms版のデータとは共有されません。また、ブラウザのデータを削除すると登録内容も失われるため、重要な記録の唯一の保存先としては使用しないでください。

## 入力チェック

- 日付が有効な日付であること
- カテゴリが選択されていること
- 金額が1円以上の整数であること

## 現時点の制限

- ユーザー認証やクラウド同期はありません。
- データは利用中のブラウザ内に保存されます。
- 本番運用向けのサーバー、データベース、バックアップ機能はありません。
