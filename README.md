# AIsample1 - かんたん家計簿

Windows Forms (.NET 8) で作成したシンプルな家計簿アプリです。

## 機能
- 日付、カテゴリ、金額、メモを入力して支出を登録
- 支出一覧を表示
- 選択した支出を削除
- 合計金額を自動計算
- 金額は1円以上で入力

## Visual Studioでの実行
1. WindowsにVisual Studio 2022と「.NET デスクトップ開発」ワークロードをインストールします。
2. AIsample1.sln をVisual Studioで開きます。
3. ソリューションエクスプローラーで AIsample1 を右クリックし、「スタートアップ プロジェクトに設定」を選択します。
4. F5 キーを押して実行します。

## テスト
Visual Studioの「テスト」→「テスト エクスプローラー」から「すべて実行」を選びます。

## データ保存について
現在、データはアプリ実行中のメモリ内だけに保存されます。アプリを終了すると登録内容は消えます。ファイルやデータベースへの永続保存は未実装です。
